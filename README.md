# ATM Banking Management System

A Java-based ATM Banking Management System developed using Java Swing, JDBC, and MySQL. The application provides a graphical user interface for performing common banking and ATM operations.

## Features

- Customer Registration
- User Login and Authentication
- Account Creation
- Deposit Money
- Withdraw Money
- Fast Cash Withdrawal
- Balance Enquiry
- Mini Statement
- PIN Change
- Transaction Management
- MySQL Database Integration

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- JCalendar
- Eclipse IDE
- Git & GitHub
